# 剑哥 AI 剪辑模板

抖音 @剑哥 视频里用的剪辑模板，免费开源。

每套模板是一个网页文件，用代码画出整条视频的画面：版式、转场、动画、字幕、手画小图。
真人位置放的是一张灰色占位图，换成你自己的画面就能出片。

## 怎么看

需要装 Node.js 18 以上。在 `templates` 文件夹里运行：

```bash
npx serve .
```

然后用浏览器打开对应的 html 文件，比如 `17_分屏对照.html`，画面会自动循环播放。
不能直接双击打开 html，要通过上面这个本地服务打开，否则图片读不出来。

## 怎么改成你自己的

- **字幕和时间轴**：在 `tim.js` 里。每句是一条 `{t0 开始秒, t1 结束秒, text 文字}`。模板里的画面是按台词里的关键词出场的，改了台词，模板里对应的关键词也要一起改。
- **真人画面**：把你的视频按每秒 30 帧导出成图片，命名为 `0001.jpg`、`0002.jpg`……，放进 `assets/hostf/`（横屏 1280×720）。然后把 html 里的 `const HOSTN=1;` 改成你的总帧数。
- **导出视频**：

```bash
npm i playwright-core
FILM=17_分屏对照.html node export.mjs 30 out.mp4
```

竖屏模板要加上 `W=1080 H=1440`。这一步需要本机装有 Chrome 和 ffmpeg。
